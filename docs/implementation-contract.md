# Implementation contract

The public API is include/passagelab/core.hpp and io.hpp, owned by the root implementer. Request changes rather than modifying those headers independently.

Units: metres/radians, right handed Z up, JSON quaternion [x,y,z,w]. Contact is invalid. Unknown distance is absent, never zero. All paths use shortest-arc SLERP and linear translation. A solved path passes independent discrete validation, not continuous certification. Physical bounds constrain the whole body using world AABBs; sampling bounds constrain its reference point. Scene hashes exclude revision and hash fields and cover all computation inputs (including config). Reference paths are separate data, never planner input. Config time_limit <= 0 disables the wall-clock deadline for deterministic operation-budget runs.

Geometry ownership: src/geometry.cpp, tests/test_geometry.cpp. Planner ownership: src/planning.cpp, src/ompl_adapter.cpp, tests/test_planning.cpp. Viewer ownership: apps/desktop.cpp, docs/viewer.md. Root owns everything else. Each worker stages only its own files and commits one cohesive change. Do not change CMakeLists.txt; tell root any target/dependency changes. Tests use Catch2 v3. Dependencies are Eigen3, fcl, ompl, nlohmann_json, Catch2, glfw3, glad and imgui with GLFW/OpenGL3 bindings. Build lives in build/windows. Do not start another build while root is building.

Geometry: custom SAT determines boxes' collision relation; FCL only supplies separated box distances and witnesses. Sphere queries analytic. Static obstacle BVH supports both collision candidate rejection and nearest-distance lower-bound pruning. Validator stats are per instance. motion must stop on invalid config, cancellation, excessive sample count or uncertainty; include both endpoints. Pose and geometry input validation must reject nonfinite values.

Planning: self-written SE3 RRT-Connect, both tree roots retain identity, validate remaining bridge before claiming success. Enforce cancellation and budgets within Connect as well as outer loop. Export <=4000 search edges. validate_path checks scene hash/revision, start/goal and all edges. optimize preserves original on failure and revalidates; evaluate returns incomplete if resource/stop interrupts distance sampling. OMPL adapter uses same validation semantics, reports differences honestly.

Viewer: OpenGL 3.3 core, simple shaders and generated cube/sphere meshes, ImGui panels, orbit/pan/zoom, picking, pose and dimensions edits, scene loading, plan/cancel with immutable snapshots and request/revision IDs, playback/scrub/step, original vs optimized, tree/ghosts/collision/distance overlays, JSON export. Main thread owns GL. Background std::jthread owns computation. Old results are discarded after edits. Provide --smoke-test (create context/render a few frames and exit), --screenshot <path.ppm> (deterministic rendered demo frame), and optionally --frames N for capture automation. Root handles packaging.
