# PassageLab v0.2.0

PassageLab is a Windows C++20 desktop and command-line tool for planning rigid-body motion through constrained 3D environments. This release completes the first-version design scope (P0-P6); P7 extensions remain optional.

## Download and run

Download `PassageLab-0.2.0-windows-x64.zip`, extract it, and run `Start PassageLab.cmd`. Requires Windows x64 and an OpenGL 3.3 graphics driver. Application dependencies and app-local Visual C++ runtime DLLs are included.

The release also includes the ZIP SHA-256 file, package verification JSON and an actual three-scene demonstration video. Source and documentation are available at the `v0.2.0` tag.

## Features

- Self-written SE(3) RRT-Connect with operation/time budgets and cooperative cancellation, plus an OMPL comparison adapter.
- Boxes, spheres and compound bodies; analytical queries, OBB SAT, feature distances, static BVH and explicit discrete motion validation.
- Three parameterized demonstrations, validated shortcut optimization and independent path rechecking.
- Pose/dimension editing, playback, picking, camera controls, search-tree inspection and minimum sampled-clearance navigation.
- Matched planar-XY and full-SE(3) planning, strict versioned JSON, stale-result rejection and source/request/validation diagnostics.
- Reproducible CLI experiments, build/verification/package scripts, recorded raw results and rendered demonstrations.

## Validation

- 40/40 CTest cases and 75/75 application-level input checks passed.
- All three fixed-seed demonstrations solved; six original/optimized paths passed finer 0.02-resolution rechecks.
- 690 recorded experiments: 640 solved and 50 budget-exhausted, retaining every outcome. Standard baseline/comparisons solved 360/360.
- A fresh source-only build passed on the reference Windows host using the pinned dependency installation.
- The extracted portable package passed 14 binary hash checks, three demo solves, six fine path checks, desktop self-tests and 25 interaction checks with a system-only PATH.

The package's bundled documents preserve the pre-publication verification snapshot; the repository documents include the public download links.

Validation is discrete and does not certify continuous collision freedom. Budget exhaustion is not a proof of infeasibility. Other physical machines, GPUs and DPI/input-device combinations have not been independently validated. GitHub Actions status is reported separately from local acceptance. Arbitrary meshes, dynamics and continuous collision certification are outside this first-version release.
