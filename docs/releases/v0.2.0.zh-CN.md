# PassageLab v0.2.0 中文发布说明

[中文项目介绍](../../README.zh-CN.md) · [中文操作与演示](../demo.zh-CN.md) · [English release notes](v0.2.0.md) · [公开发布页](https://github.com/CG-Yici/PassageLab/releases/tag/v0.2.0)

本版是 Windows 三维刚体路径规划工具，完成设计首版 P0–P6：三场景、自研规划与几何检查、桌面交互、路径简化、命令行、实验及交付。软件界面仍为英文，本次增加中文说明和控件对照，没有修改已发布的软件功能。

## 下载内容

| 文件 | 用途 |
|---|---|
| `PassageLab-0.2.0-windows-x64.zip` | 可运行的软件包；完整解压后运行 `Start PassageLab.cmd`，需要 Windows x64 / OpenGL 3.3 |
| `PassageLab-0.2.0-windows-x64.zip.sha256` | 软件 ZIP 的 SHA-256 校验值，可用 PowerShell `Get-FileHash 文件路径 -Algorithm SHA256` 核对 |
| `PassageLab-0.2.0-windows-x64.verification.json` | 解压软件包后的运行和二进制校验记录 |
| `passagelab-demo.mp4` | A/B/C 共 15 秒真实路径播放，无旁白 |
| `PassageLab-0.2.0-Chinese-Guide.zip` | 本次补充的离线中文项目介绍、操作说明、图片和字幕视频；解压后用浏览器打开 `index.html` |
| `PassageLab-0.2.0-Chinese-Guide.zip.sha256` | 中文文档 ZIP 的校验值，与软件 ZIP 校验值分开 |
| `Source code` | GitHub 提供的源码压缩包，需要构建；不是便携程序 |

中文文档作为发布后的补充更新进入 `main`。**原 `v0.2.0` 标签和软件 ZIP 保持不变**，所以原源码标签和软件包不包含本次新增中文文件；请使用仓库中文入口或单独下载中文指南。
