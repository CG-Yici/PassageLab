| 检查项 | 核对方式与结果 |

| 播放与检查 | 说明路径进度不是时间/等弧长；单步为进度 ±0.02；搜索边检查与最终路径分开 |

| 命令行示例 | 使用已发布软件包的 CLI：A/B/C 三次求解、C 两次精细复核、零预算示例、OMPL B 对照均符合预期 |

| 桌面控件流程 | 使用发布包对 A/B/C 各执行 25 项真实控件输入回放，75 项均通过；本次是复验，不新增测试种类 |
| 数据一致性 | 核对原始汇总：690=360+330，640 成功、50 预算耗尽；窄开口 12/30、共同端点 SE(3) 30/30、平面 0/30 |

## 页面与交付检查

- 四份中文正文的 27 个本地 Markdown 引用逐一检查，目标均存在；中文 UTF-8 无替换字符。
- Chrome 本机 HTTP 预览中，中文、表格和四张原有演示图片正常显示；当前 1920 像素宽视口无整页横向溢出。四个章节目标均存在，点击“演示与操作”已正确跳转。
- 内置视频实际时长 15 秒，可正常播放；中文字幕轨加载成功，已观察到字幕显示。三段字幕与 A/B/C 各 5 秒的录制时序一致。
- 离线 HTML 的图片、视频、CSS 和字幕全部内置，无外部渲染资源依赖；在线参考资料仍需要网络。ZIP 完整性和独立 SHA-256 校验文件均检查。
- 浏览器工具禁止直接导航 `file://`，因此视觉与媒体检查使用仅提供该 HTML 的本机 HTTP 服务；没有把它写成已完成所有浏览器的本地文件模式测试，也没有更改浏览器安全配置。
- 原软件 ZIP 的 SHA-256 与原验收记录一致；生产源码未修改。新增中文文档 ZIP 是独立附件，不替换原软件包。

## 中文理解覆盖

按首次接触项目的中文读者视角检查六项任务：能选对下载文件并启动；能解释项目解决的问题；能完成规划/播放/简化；能保存并重载验证；能辨别成功、预算耗尽和未验证预览；能解释结果的准确保证范围。对应答案和自检题均已写入演示指南，不要求读者先阅读英文技术说明。

这是一轮文档事实核对、操作验证和可读性审查，不是招募中文用户完成的人体可用性研究，不能保证每个人都无需进一步帮助。当前桌面软件仍为英文；中文按钮对照和离线说明降低阅读门槛，但不宣称完成界面汉化。

程序层面的原 40 项测试与本次文档验收分开计数。详细本机运行输出位于当前工作区 `results/chinese-docs-acceptance/`；选入仓库的摘要位于 `benchmarks/data/worktree-0.2.0/chinese-docs-review.json`。原软件包与生产源码指纹保持不变。
